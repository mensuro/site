# Mensuro website: working rules

- Never push to `main`. Work on a branch and open a pull request; Nick reviews and merges.
- Static site only: HTML, CSS and vanilla JS. No frameworks or build step unless Nick asks.
- Follow the Mensuro brand guide: deep ink #14263D, modern teal #36C2AE (on dark only), deep teal #237E71 (accents on light), soft white #F5F8FC; Manrope for headings, Inter for body and numbers.
- Copy stays plain and accurate. No claims the product can't back up yet (for example, "validated" only once the validation tests exist).
- No secrets in this repo. It is public. Keys belong in Netlify environment variables.
- Keep pages working at phone width and accessible: real labels, visible focus, alt text.
